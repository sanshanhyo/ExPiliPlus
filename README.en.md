<h1 align="center">ExPiliPlus</h1>

<p align="center">
  A third-party Bilibili client built with Flutter.<br>
  Based on <a href="https://github.com/bggRGjQaUbCoE/PiliPlus">PiliPlus</a>,
  with additional experimental and personalization features.
</p>

## Download

Visit the [ExPiliPlus releases](https://github.com/sanshanhyo/ExPiliPlus/releases/latest) page.

## Features

- Main features from [PiliPlus](https://github.com/bggRGjQaUbCoE/PiliPlus)
- Custom application fonts and theme colors
- GIF recording (not supported on Windows)
- Share ticket support and random video playback
- Interface languages: Simplified Chinese, Traditional Chinese, and English
- Viewing statistics based on Bilibili watch history

## Relationship with PiliPlus

PiliPlus is maintained by [bggRGjQaUbCoE](https://github.com/bggRGjQaUbCoE) and builds on work from projects including [Pilipala](https://github.com/guozhigq/pilipala) and [PiliPalaX](https://github.com/orz12/PiliPalaX). ExPiliPlus is an independently maintained, unofficial derivative that explores additional features and interactions. For an experience closer to the upstream design and release cadence, use [PiliPlus](https://github.com/bggRGjQaUbCoE/PiliPlus).
