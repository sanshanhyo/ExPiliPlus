## 与 PiliPlus 的关系

[PiliPlus](https://github.com/bggRGjQaUbCoE/PiliPlus) 由 [bggRGjQaUbCoE](https://github.com/bggRGjQaUbCoE) 维护，并建立在 [guozhigq/Pilipala](https://github.com/guozhigq/pilipala) 与 [orz12/PiliPalaX](https://github.com/orz12/PiliPalaX) 等开源项目的工作之上。在此向这些项目及所有参与开发、维护和贡献的前辈们表示诚挚感谢。

PiliPlus 已经**能够**满足大多数用户的日常使用需求。ExPiliPlus 是一个独立维护的非官方衍生项目，在 PiliPlus 的基础上加入更具个性化、实验性，且未必适合所有用户的功能。如果你希望获得更接近上游设计、维护节奏和使用体验的版本，我们建议**优先选择** [PiliPlus](https://github.com/bggRGjQaUbCoE/PiliPlus)。

ExPiliPlus 的初衷是探索出于个人兴趣提出的功能与交互方式。项目计划持续跟进 PiliPlus 的上游变化，并在此基础上开发和维护自己的扩展功能；适合回馈上游的改进，也会尽可能提交给 PiliPlus。
